# PUBG Finish Placement Prediction

## Overview
This project predicts a player's final finish placement (winPlacePerc) in PUBG matches using machine learning techniques. The project includes data preprocessing, outlier treatment, exploratory data analysis (EDA), feature engineering, model training, and performance evaluation.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
- Data Cleaning
- Missing Value Handling
- Outlier Treatment
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation
- Finish Placement Prediction

## Machine Learning Models
- Ridge Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Evaluation Metrics
- R² Score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)

## Dataset
PUBG Finish Placement Prediction Dataset from Kaggle.

## Objective
To build a machine learning model that accurately predicts a player's final placement in PUBG matches and identify the gameplay factors that most influence match performance.
